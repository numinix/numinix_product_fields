Numinix Product Fields


Installation for Zen Cart v2.0+

NOTE: This version only supports Zen Cart v2.0 and above. For older versions, please use a previous release.

  1. Backup your files and database
  2. Upload all files in this package while maintaining the directory structure (rename YOUR_ADMIN to your custom admin folder name except for the ones in catalog/YOUR_ADMIN/includes/npf_includes/prebuilt_fields folder)
  3. Reload your admin, the module will self-install the additional page located at ADMIN > CATALOG > NUMINIX PRODUCT FIELDS
  4. Add additional fields using the pre-Built sets in ADMIN > CATALOG > NUMINIX PRODUCT FIELDS
  5. Apply Core File Integration - Choose one of two methods (see detailed instructions below):
    • Method 1 (Recommended): Use the automatic override generator
    • Method 2 (Fallback): Manual core file modifications
  6. File uploads will be saved to the media directory so make sure that exists, or you can change this in the configuration menu
  7. (Optional) To display numinix product fields in product info page
    Open includes/modules/YOUR_TEMPLATE/templates/YOUR_TEMPLATES/templates/tpl_product_info_display.php and find:
    Select code
     <?php echo (($flag_show_product_info_manufacturer == 1 and !empty($manufacturers_name)) ? '<li>' . TEXT_PRODUCT_MANUFACTURER . $manufacturers_name . '</li>' : '') . "\n"; ?>

    Select code

<?php
  if(count($numinix_fields_display ) > 0) { ?>
<?php foreach ($numinix_fields_display as $field => $value) {

  8. See the TIPS page for more details about the usage of this plugin.

Core File Integration for Zen Cart v2

NPF v4.1 offers TWO methods for integrating with Zen Cart v2:

Method 1: Automatic Override Generator (RECOMMENDED) ✨

NPF provides an automatic override file generator that eliminates manual core file editing!

What is the Override System?

Zen Cart v2.0+ includes an official override system for product modules. When loading files like collect_info.php, Zen Cart searches in this order:

  1. YOUR_ADMIN/includes/modules/product/collect_info.php (override - NPF uses this!)
  2. YOUR_ADMIN/includes/modules/collect_info.php (base - remains untouched)
Benefits:
  • ✅ No manual editing of core Zen Cart files required
  • ✅ Easier to upgrade Zen Cart (core files remain pristine)
  • ✅ Easier to upgrade NPF (just replace override files)
  • ✅ Official Zen Cart methodology
  • ✅ One-click automated process
How to Use the Override Generator:
  1. Upload npf_generate_overrides.php from the NPF package to your YOUR_ADMIN directory
  2. Login to your admin panel as a superuser
  3. Access the generator via browser: http://yourstore.com/YOUR_ADMIN/npf_generate_overrides.php
  4. Click "Generate Override Files" button
  5. Verify the success message
  6. Delete the generator script (npf_generate_overrides.php) for security
  7. Test product editing to verify NPF fields display and save correctly
Generated Files:

The generator creates these override files in YOUR_ADMIN/includes/modules/product/:

  • collect_info.php - Loads NPF field data when editing products
  • update_product.php - Saves NPF field data when creating/updating products
How to Revert Changes if Issues Occur:

If you encounter problems after generating override files, you can easily revert:

  1. Delete or rename the override files:
    • YOUR_ADMIN/includes/modules/product/collect_info.php
    • YOUR_ADMIN/includes/modules/product/update_product.php
  2. Zen Cart will automatically fall back to using the base files (without NPF integration)
  3. Your custom fields will not be lost - they remain in the database
  4. You can then try Method 2 (manual editing) or contact support for assistance

Migration Guide from v3.x to v4.0

IMPORTANT: Version 4.0 is a major refactoring that only supports Zen Cart v2.0+. If you are using an older version of Zen Cart, you must stay on v3.x.

What Changed in v4.0?

  • Zen Cart v2 Only: Dropped support for Zen Cart versions prior to v2.0
  • Observer Pattern: Now uses Zen Cart's observer/notification system for field display
  • Minimal Core Changes: Significantly reduced core file modifications required
  • Cleaner Integration: Better separation between NPF code and Zen Cart core
  • Override System (v4.1+): Automatic generator eliminates manual core file editing

Migration Steps

  1. Backup Everything: Make complete backups of your files and database before upgrading
  2. Verify Zen Cart v2: Ensure you are running Zen Cart v2.0 or higher
  3. Backup Current NPF Installation: Note all your custom fields and their configurations
  4. Remove Old Core Modifications:
    • If you manually edited core files in v3.x, restore the original files or remove NPF code blocks from:
    • YOUR_ADMIN/includes/modules/collect_info.php (if edited)
    • YOUR_ADMIN/includes/modules/update_product.php (if edited)
    • Remove similar blocks from document_product and document_general modules if applicable
  5. Upload New Files: Upload all v4.1 files, overwriting the old ones
  6. Apply New Integration:
    • Recommended: Use the automatic override generator (see Installation section, Method 1)
    • Alternative: Follow the manual modifications (see Installation section, Method 2)
  7. Test Thoroughly:
    • Verify fields display correctly in product edit pages
    • Test creating a new product with NPF fields
    • Test updating an existing product
    • Verify field data is saved and retrieved correctly

Troubleshooting Migration

  • Override generator fails: Check file permissions on YOUR_ADMIN/includes/modules/product/ directory, ensure you're logged in as superuser
  • Fields not displaying: Verify the override files exist in YOUR_ADMIN/includes/modules/product/ or that manual modifications were applied correctly
  • Data not saving: Check that update_product.php override exists or manual modifications are in place
  • Observer not loading: Verify the auto_loader configuration is correct
  • SQL errors: Make sure helper files have proper permissions and paths
  • Need to revert changes: Simply delete the override files in YOUR_ADMIN/includes/modules/product/ and Zen Cart will use the original files

Need Help? If you encounter issues during migration, please check the Help section or contact support.

Tips
  • Most of the fields have been setup for data entry only. To show them on your store's website you will need to modify your plugins and templates according to your project's specifications.
  • Create your own fields at the bottom of CATALOG > NUMINIX PRODUCT FIELDS.
  • To show the information stored in the fields, add them to the list in CONFIGURATION > NUMINIX PRODUCT FIELDS > FIELDS TO DISPLAY ON PRODUCT INFO PAGE, separate them by commas (without spaces), eg. If the name of the field is "Additional Skus", the name to add in the list would be additional_skus.
  • To add many fields to the list mentioned before, add them separated by commas without spaces. Eg. additional_skus,my_test_field.
Instructions
  1. Accessing the Plugin
    1. Log in to your Zen Cart Admin Panel.
    2. Navigate to Configuration > Numinix Product Fields.
    3. Here, you can configure general settings for the plugin.
  2. Adding Custom Fields
    • Go to Catalog > Numinix Product Fields in the admin menu.
    • Click “Add New Field”.
    • Enter the Field Name (e.g., "Material", "Manufacturer Warranty").
    • Select the Field Type:
      1. Text: Simple text input.
      2. Checkbox: Yes/No options.
      3. File: A File Input.
    • Click “Add Field” to create the field.
  3. Assigning Fields to Products
    • Go to Catalog > Categories/Products.
    • Select a product to edit or add a new product.
    • Scroll down, and the new fields will be displayed.
    • Assign values for each custom field created earlier.
    • Click “Save” or “Update” to apply changes.
  4. Displaying Custom Fields on Product Pages
    1. If the fields are not showing:
      • Ensure that your template supports Numinix fields.
      • Open Configuration > Numinix Product Fields and update the field to be displayed, separating each field with “,”.
      • Confirm Installation Step 8 has been completed and the file includes/modules/YOUR_TEMPLATE/templates/YOUR_TEMPLATES/templates/tpl_product_info_display.php has been properly saved on the server.
  5. Managing Fields
    1. To delete a field, click Delete, but note that this will remove it from all products.
  6. Troubleshooting Common Issues
    • Fields Not Showing on Product Pages
      1. Make sure you’ve added the necessary PHP code in tpl_product_info_display.php.
      2. Confirm the Fields have been added to the configurations.
      3. Clear the Zen Cart cache and refresh the page.
    • Custom Fields Not Saving
      1. Check database permissions; the plugin needs access to modify product data.
      2. Try re-saving the product after assigning the field values.
    • Plugin Not Working Correctly
      1. Ensure you're using Zen Cart v2.0 or higher. This version only supports Zen Cart v2.
      2. Check for conflicts with other plugins by temporarily disabling them.
Uninstall
  1. Remove edits performed in the installation procedure.
  2. Delete all uploaded files from your store.
  3. Patch your database by copying and pasting the contents of uninstall.sql into ADMIN > TOOLS > INSTALL SQL PATCHES.
  4. If uninstalling only specific fields, you can simply delete their directories in YOUR_ADMIN/includes/npf_includes/.
